# Компьютер для сервера организации

Для первых тестов рекомендуем **2 vCPU (или два логических процессора), 4 ГБ RAM и 20 ГБ свободного места на диске установки**. Это предварительный стартовый профиль, а не измеренный минимум и не обещание определённого числа сотрудников или обращений. Нагрузочный тест и измерение минимальной конфигурации ещё нужны.

Windows-мастер предназначен для x64; основной пользовательский сценарий — Windows 11. Серверная часть отдельно проверена на Windows Server 2022 в CI, что не заменяет полный прогон GUI/UAC. Linux-профиль проверялся на Ubuntu Server 24.04 LTS amd64 с Docker Engine и Compose v2. ARM и другие дистрибутивы не заявлены как проверенные.

20 ГБ — запас для подготовки, приложения и начальной базы. Фото, видео, рост PostgreSQL, журналы и резервные копии требуют дополнительного места. Планируйте хранение и срок хранения вложений по своей работе; копии желательно хранить отдельно от рабочего диска. Для центрального портала действуют отдельные рекомендации в [плане размещения портала](OWNDESK-PORTAL.md).

Сервер должен оставаться включённым, не переходить в сон и иметь интернет для публичного доступа и подключённых интеграций. Подготовка загружает компоненты. Обычная установка через OwnDesk использует публичный адрес организации и туннель — сотрудникам не нужно находиться рядом с сервером.

Сотрудникам нужен браузер и доступ к HTTPS-адресу организации. Устанавливать сервер OwnDesk на каждый рабочий компьютер не требуется. Приведённый профиль относится к серверу, а не к компьютерам сотрудников.

## Что проверяет Windows-мастер

Вкладка установки показывает число логических процессоров, общую физическую RAM и свободное место на диске Program Files. Проверка только читает локальные сведения, не отправляет их в сеть и не записывает в журнал. Нехватка относительно рекомендации или недоступность показателя отображается как совет и не запрещает установку. Проверки совместимости ОС и прав администратора выполняются отдельно.

Данные показываются при открытии окна. Это не постоянный мониторинг и не гарантия свободного места на всё время работы. Перед крупным импортом, обновлением или настройкой резервных копий проверяйте запас диска снова.
