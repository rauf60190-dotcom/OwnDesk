# Анонимная проверка из внешней сети

Workflow `Public visitor check` запускается вручную на отдельном Windows runner GitHub. Он проверяет работающий портал `https://owndesk.work`, а не собирает и не разворачивает локальный кандидат. Коммит в отчёте относится к проверочному инструменту, а не к версии установленного портала.

Проверяются публичная главная о продукте, отдельная страница входа, конфиденциальность, правила, экран 390 px, доступность health/options и отказ личных API `auth/me`, `auth/security`, `portal/installations` гостю. Для API отказа требуется JSON и статус 401/403: HTML-блокировка Cloudflare не считается подтверждённой защитой приложения.

Контекст браузера новый и неавторизованный. Инструмент не вводит реквизиты и коды, не создаёт аккаунты и не запрашивает письма. В браузере блокируются методы кроме GET/HEAD, внешние домены и service workers. API-проверки выполняются тем же браузером только для заданных GET-маршрутов своего HTTPS-домена, с `credentials: omit` и отказом от редиректов. Снимки делаются только после подтверждения публичной главной; тела ответов личных API, cookies и сетевые трассы не сохраняются.

Запуск отдельный от проверки исходников: выключенный ноутбук, недоступность туннеля или сетевая защита могут сломать внешнюю доступность, хотя исходный код собирается. При challenge/CAPTCHA проверка завершается без обхода. Не следует ослаблять защиту ради зелёного результата.

Успех подтверждает доступность для гостя из другой сети. Он не заменяет регистрацию по настоящему письму, вход нового Google-аккаунта, установку организации и работу сотрудника с другого устройства. Эти сценарии остаются отдельной приёмкой.

## Результат — 20 ноября 2026

[Прогон 44721732984](https://github.com/rauf60190-dotcom/OwnDesk/actions/runs/44721732984) завершился успешно на внешнем Windows runner с Chromium. Коммит проверочного инструмента: `b427b97b35975b9e89ac6f737cfddf3ee4294619`; это не номер версии работающего портала.

- Главная показывает продукт, отдельная страница входа открывается.
- Обе страницы политик отображаются; главная на 390 px не имеет горизонтальной прокрутки.
- Health/options вернули JSON 200; три личных API вернули JSON 403 без авторизации.
- Не было изменяющих запросов, сторонних запросов или ошибок JavaScript. Аккаунты не создавались, письма не запрашивались.
- Артефакт с отчётом и публичными снимками скачан, SHA-256 сверён; снимки проверены визуально.

Результат относится к указанному моменту проверки. Постоянная доступность всё ещё зависит от работающего ноутбука, сети и туннеля. Настройки и службы при проверке не изменялись.
