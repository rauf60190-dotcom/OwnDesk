# Локальная подготовка исходников к ревью

`tools/prepare_source_review.py` создаёт новую копию исходников вне рабочей папки проекта. Он не создаёт GitHub-репозиторий и не публикует код.

```powershell
python tools/prepare_source_review.py --output ../owndesk-source-review --report ../source-review.json
```

Рабочая `.runtime`, базы, логи, заполненные `.env`, ключевые конфигурации, node_modules, dist, загруженные бинарники, архивы и окружения исключаются до копирования. `.env.example` допускается как пустой шаблон. Ссылки/junction и hardlinkфайлы не копируются. Экспорт ограничен по числу и размеру файлов и сверяет SHA каждого скопированного файла.

Графические ресурсы допускаются только по перечню `tools/source-assets-reviewed.json` с совпадающим SHA. В текущем перечне3снимка собственного демо/интерфейса: отчёты и очередь на desktop/mobile. Обновление изображения требует нового просмотра, а не только изменения хеша. Лицензионные тексты third_party сохраняются; их наличие не подтверждает все обязательства распространения автоматически.

Простой локальный scanner отмечает характерные приватные ключи и токены провайдеров. В отчёт выводятся путь, строка и тип, без значения. Код возврата ненулевой при таких находках. Ноль находок не гарантирует отсутствия всех возможных секретов: необходимы проверка diff, Git-индекса и отдельное разрешение владельца на публичную публикацию. При находке реального уже раскрытого секрета нужна его замена у провайдера, а не только удаление строки.

После ревью можно создать локальный Git-репозиторий. Настройка remote, отправка кода и изменение видимости выполняются отдельно. Прежде чем делать commit/push, проверьте, что в индексе есть только ожидаемые исходники, LICENSE и notices. Не добавляйте результаты тестов, сборок и полный отчёт с внутренними путями автоматически.

У текущего кандидата согласована MIT для собственного кода. Публичный репозиторий, защищённые ветки и SignPath ещё не подключены. Подготовленная исходная копия не является подписанным Windows-установщиком.
