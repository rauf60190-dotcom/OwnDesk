# Приёмка окончательного Windows-установщика

Статус: протокол подготовлен, полный прогон нового EXE не выполнен. Отчёты проверки ZIP, распаковки и предпросмотра окна не заполняют строки ниже автоматически.

Для отдельной проверки серверной части подготовлен [прогон настоящей LocalService на одноразовом CI runner](CI-WINDOWS-SERVICE.md). Его результаты относятся к запуску приложения и восстановлению процесса, а не к GUI, UAC, реальной перезагрузке и внешнему подключению.

Перед началом зафиксировать: версию и SHA-256 окончательного EXE, SHA-256 payload, исходный коммит, версию Windows, издателя и результат Authenticode. Использовать чистую тестовую систему, отдельную организацию и синтетические данные. Не отключать защиту и не использовать рабочую базу. При блокировке записать результат и причину; не помечать запуск успешным.

| Сценарий | Ожидаемый результат | Статус |
|---|---|---|
| Реальное скачивание | Хеш совпадает с опубликованным, интернет-метка сохранена | Не выполнено |
| Издатель и timestamp | Подпись и цепочка действительны, байты после подписи не менялись | Ожидает подписи |
| Отмена на первом экране | Нет загрузки компонентов, извлечения payload и новой службы | Не выполнено |
| Согласие и отказ в UAC | Подготовка не продолжается, понятное сообщение об отмене | Не выполнено |
| Первый запуск | Открывается полный мастер; ошибки остаются доступны пользователю | Не выполнено |
| Отказ от подключения | Код не передан порталу, новая организация не активирована; сохранённые компоненты описаны явно | Не выполнено |
| Подключение | Новый код создаёт правильный HTTPS-адрес и открывает мастер организации | Не выполнено |
| Данные и права | LocalService, закрытые каталоги, приватные вложения недоступны постороннему пользователю | Не выполнено |
| Повторный запуск | Нет случайной повторной установки, доступны функции управления | Не выполнено |
| Перезагрузка тестовой Windows | Служба и адрес восстанавливаются, записи и файлы сохранены | Не выполнено |
| Обновление | Создана проверенная резервная копия, новая программа запускается с текущими данными | Не выполнено |
| Сбой обновления и возврат | Возвращается совместимая программа, новые записи не заменяются старой базой | Не выполнено |
| Удаление службы | После явного подтверждения удаляется нужная служба, данные и файлы программы сохранены | Не выполнено |
| Защита Windows | Зафиксированы реальные результаты Defender, SmartScreen и App Control; различаются их причины | Не выполнено |

Протокол должен содержать фактические результаты, время, безопасные снимки ошибок и ссылки на журналы в закрытом хранилище. Не публиковать токены, одноразовые коды, базы и персональные данные. Даже успешная подпись не гарантирует отсутствие SmartScreen на всех компьютерах.
