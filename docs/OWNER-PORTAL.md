# Кабинет владельца после появления мастера установки

Кабинет нужен и после установки: он предоставляет дистрибутив, одноразовую привязку нового сервера, состояние установок, переход в готовую организацию, отзыв подключения и настройки безопасности аккаунта. Рабочие обращения, сотрудники, Telegram и файлы находятся в самой организации.

В интерфейсе 0.4.36 сохранены существующие API и действия. Обновлены тёмно-синее оформление, блоки первого запуска, карточки, адаптация под телефон и текст. Выбор Windows/Ubuntu показывает инструкции для соответствующего мастера; архив содержит оба варианта. Доступная версия архива берётся с портала, а не жёстко задаётся интерфейсом.

Основной Windows-сценарий — `Setup-OwnDesk-Server.cmd`, который подготавливает Python и компоненты. Старая рекомендация ручной установки Python 3.12 и `Setup-OwnDesk.cmd` убрана из основного пути. Для Ubuntu указаны 24.04 LTS x86-64 и `sudo bash Setup-OwnDesk.sh`. Одноразовый код вводится в мастер, а не обязательно в консоль; команда ручного подключения сохранена в дополнительном раскрывающемся разделе.

Для уже подключённого сервера новый код не нужен: владелец открывает пространство из списка, а сотрудников приглашает в самой организации. Аккаунты портала и владельца организации независимы. Мастер и серверная логика этим изменением не переписывались.

Проверки: TypeScript/Vite, отдельная визуальная среда с вымышленными данными и отключённым write API, переключение ОС, инструкции и кнопка скачивания, ширина 390 px без горизонтальной прокрутки. После обновления проверен настоящий кабинет владельца на `https://owndesk.work` с сохранённой сессией и существующей подключённой организацией.
