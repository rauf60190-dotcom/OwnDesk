# Автоматическая подготовка Python в Windows

Рабочий установщик `Setup-OwnDesk-Server.cmd` запускает подготовку средствами PowerShell и .NET. Заранее установленный Python ему не требуется. В первом тёмно-синем окне показаны загрузка, проверка и распаковка; затем открывается основной мастер OwnDesk.

Используется официальный архив Python Software Foundation **Python 3.14.10 x64**. Версия, размер и SHA-256 зафиксированы в `infra/windows-python.json`. Перед запуском проверяются размер, хеш архива, допустимость путей ZIP, действительная Authenticode-подпись Python Software Foundation и совместимость интерпретатора. Несовпадение хеша или подписи останавливает подготовку. Защита Windows остаётся действующей.

Python хранится в `%ProgramFiles%\OwnDesk\Bootstrap\python-3.14.10-20261026`. Каталог доступен администраторам, SYSTEM и LocalService; LocalService имеет права чтения и выполнения. Для рабочего сервера создаётся отдельная копия в `%ProgramFiles%\OwnDesk\Server\runtime\python` и отдельное окружение с зависимостями. Уже зарегистрированная служба обновляется отдельным сценарием, без автоматической замены её окружения при открытии мастера.

При повторном запуске сверяются хеши сохранённых файлов. Незавершённый скачанный файл не становится установленной средой; повторная попытка проверяет архив заново. При обнаружении изменённых файлов подготовка останавливается с диагностикой. Закрытие окна загрузки отменяет подготовку. Ошибки первого этапа записываются в `.runtime/bootstrap-error.log` рядом с распакованным дистрибутивом, ошибки окна мастера — в `.runtime/server-window.err.log`. Не удаляйте базу или ключи организации при ошибке Python: каталог Bootstrap является отдельным кэшем программы.

Проверено на текущем Windows-ноутбуке: загрузка и распаковка через PowerShell без обращения к имеющемуся Python, подпись PSF, Python 3.14.10 / Tk 9.0.4, повторное использование кэша, отказ при изменении файла с последующим восстановлением оригинала и открытие настоящего окна мастера. На скачанном интерпретаторе проверена отдельная служба LocalService с PostgreSQL, API, Caddy, остановкой, сохранением базы и восстановлением после сбоя. Полный набор на Python 3.14 дал 131 успешную проверку на SQLite и две успешные проверки на PostgreSQL. Проверка на чистой ОС и реальная перезагрузка остаются отдельными шагами.

Сервер сохраняет поддержку Python 3.12 для прежних окружений; новые автоматические установки Windows используют 3.14. Политика обновления версии — выпуск нового дистрибутива OwnDesk с новой закреплённой версией после тестов.

Источник: [Python 3.14.10](https://www.python.org/downloads/release/python-31410/), [официальные файлы Windows](https://www.python.org/ftp/python/3.14.10/).
